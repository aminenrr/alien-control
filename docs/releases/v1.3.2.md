**Alien Controls 1.3.2**: lights switch without flashing.

### Fix
- Turning the keyboard, rear ring or Alienhead on or off, or Ctrl + Alt + F (full / off / 50%), made the lights flash first. Now only the light that changes is updated: the keyboard over its own HID channel, the ring and Alienhead with their own commands only. The keyboard's new colors are ready before it lights up, so the old colors never show.
- With a keyboard effect running, switching still uses the full lighting update.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
