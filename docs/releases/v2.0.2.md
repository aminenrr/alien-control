**Alien Controls 2.0.2**: stability fixes on top of 2.0.1. No new features.

### Fixed
- **Waking from sleep in G-Mode**: if the laptop doesn't answer the G-Mode check on wake, Alien Controls no longer assumes G-Mode is off. It tries again and leaves your mode alone. Your GPU overclock is checked against the driver after waking.
- **Stuck fan / mode commands**: when a hardware command hangs, it is closed properly before the next one runs, so two commands can't hit the laptop at once.
- **Quitting during an overclock change**: the app waits for the change to finish, then puts the GPU back to +0. If it can't, it remembers and fixes it on the next launch.
- **Switching GPU modes twice**: clicking another GPU mode while a switch is still running is ignored instead of starting a second switch.
- **OC test safety**: Revert, the 20 second timeout and a failed apply only count as done once the GPU is confirmed back at +0. If the RTX is off at launch, the reset waits until you turn it back on. Keep works as before.
