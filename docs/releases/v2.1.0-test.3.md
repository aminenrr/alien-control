**Alien Controls 2.1.0-test.3**: 2.1.0-test.2 with the Power button light switch removed. Still a test build for the CPU power drop in 2.0.3.

### Changes from test.2
- **Power button light switch removed.** It used alienfx-cli `setpower`, which stores colours in the light controller: AC, battery and a charging morph between the two (the colour cycling). The app never sends the power button again, as in 2.0.0.
- Kept: section titles with word gaps (GPU MODE, CPU BOOST...), FPS CAP title in the same style.

### If test.2 changed your power button
The colours test.2 wrote stay in the light controller until something rewrites them. From an Administrator command prompt in the folder with alienfx-cli.exe:
`alienfx-cli.exe setpower=1,2,0,255,255,0,255,255` (cyan on AC, charging and battery, no cycling).
