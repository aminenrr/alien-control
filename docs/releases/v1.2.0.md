**Alien Controls 1.2.0**: new toasts and chimes, iGPU only mode, smoother and snappier window.

### Changes
- New card toasts with a soft chime per preset (F1, F2, plug / unplug), both themes.
- **iGPU only** GPU mode: turns the RTX off (Advanced Optimus + NVIDIA set to Optimus). It shows the apps using the RTX first and locks Ultimate while it's off. Advanced Optimus brings it back without a restart. HDMI / Mini DP stay dark while the RTX is off.
- Lock badges on iGPU only and Battery when they're locked.
- Smooth card-swap switch between compact and full, faster open/close, no freeze when spamming F3/F4.
- Shows as "Alien Controls" in startup lists.
- Hardened: Windows tools are called by their full System32 path. Still zero network access.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
