**Alien Controls 1.3.1-beta.1**: a new Off menu for the lights, and F7 works after Off. Untested pre-release.

### Changes
- Lighting > **Off** opens a small menu: **Keyboard**, **Rear ring**, **Alienhead**, **All off**. Turn off any mix (for example keyboard + ring); each tap applies at once and the button shows how many are off. The power button light is never touched.
- **F7 after Off**: the keyboard is now turned off through its own brightness, with the colors kept, instead of painting it black. That should let F7 (the firmware brightness key) bring it back. Needs a test on the laptop.
- Lights you turn off stay off through color and effect changes, F1 / F2, plug / unplug, sleep and restarts.
- Fix: Spectrum and Rainbow wave no longer fall back to Static after a restart.
- Probe: if F7 (or another Alienware key) sends a report Windows can see, it is written once to `crash.log`.
