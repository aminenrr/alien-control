**Alien Controls 2.1.0-test.1**: test build for the CPU power drop in 2.0.3.

### What's in it
- 2.0.0 base: presets, CPU boost, G-Mode and the CPU W meter are the same code as 2.0.0.
- 2.0.1: overlay Move from the corner, PERF / G-MODE pills in their own colours, Metal level polish.
- 2.0.3 overlay and display: display latency, VRR / G-SYNC row for Intel and NVIDIA, overlay layout.

### Held back
- 2.0.2 (CLI timeout queue hold, G-Mode read keep, OC recovery, RTX switch gate).
- 2.0.3 ETW flush every 50 ms: off. The overlay graph may run up to ~1.5 s behind at low frame rates, as in 2.0.0.
- 2.0.3 GPU USE from the NVIDIA driver: off, GPU USE reads like 2.0.0.
