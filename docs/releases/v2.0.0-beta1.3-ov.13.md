# Alien Controls 2.0.0-beta1.3-ov.13 (overlay preview)

Overlay-only build on `beta1.3-ov`. Merges into 2.0 later through `merge/beta2`.

## FPS CAP
- APPLY button: picking a chip, the custom number or V-Sync no longer writes right away. APPLY writes them all at once and turns into SAVED.
- The sub line shows where the cap goes: the game's NVIDIA profile name and the exe (`Castlevania Belmont's Curse · Castlevania Belmont's Curse.exe`), or just the exe when NVIDIA has no profile for it. Hover it for details.
- After APPLY the app reads the profile back in a fresh driver session. If the driver didn't keep it, the status line says so.
- When the game starts again, the app checks the profile still has your cap. If something changed it back (the NVIDIA app is known to rewrite driver profiles), the status line says so instead of failing silently.
- The log now records the profile name, whether NVIDIA made it, any extra match rule (file in folder, launcher) and the value read back.

## Known issue being chased
- ov.11 / ov.12: a cap saved fine but didn't apply after restarting the game (Castlevania Belmont's Curse). Most likely the NVIDIA app rewriting the profile. This build tells us which.
