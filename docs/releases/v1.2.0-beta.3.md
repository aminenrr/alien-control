**Alien Controls 1.2.0-beta.3**: smoother view switch and open/close, cleaner chimes, iGPU only, new toasts.

### Changes
- **Smooth Compact / Full menu switch** (dip and rise) and a snappier open/close from the tray, F3 and F4.
- **Chimes without crackle**: smooth note endings and no pop when the audio device wakes up.
- **iGPU only**: a third GPU Mode button that turns the RTX off (Intel only) for the longest battery. Needs Advanced Optimus with NVIDIA set to Optimus; on Automatic Select it asks you to switch first, and it's locked in dGPU only and Ultimate. Before switching it lists the apps using the RTX (Cancel / Refresh / Turn off anyway). HDMI / Mini DP stay dark while it's off, and Ultimate is locked. Click **Advanced Optimus** to turn the RTX back on, no restart.
- **New toasts**: icon tile in the preset's color, title + detail, and the state on the right (preset pills for F2, a switch for G-Mode, a preset chip when you plug in or unplug). Legend and Fluent.
- **New chimes**: soft bell notes. Each F2 preset has its own note, G-Mode rises on and falls off, plug and unplug go up and down.
- Windows startup lists and Task Manager now show **Alien Controls** instead of "AlienControl".
- The run-on-startup task is renamed to "Alien Controls". If you had run on startup on, the old task is replaced automatically the first time this version starts.

Updating from 1.1.x: replace `AlienControl.exe`, keep the CLIs. Settings stay in `%AppData%\AlienControl`.
