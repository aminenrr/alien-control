**Alien Controls 2.0.0-beta1.3-ov.9** (overlay preview, pre-release): on top of **beta1.3**, without the beta1.4 fixes. Includes everything from [ov.8](https://github.com/aminenrr/alien-control/releases/tag/v2.0.0-beta1.3-ov.8).

### New in ov.9
- **Show on overlay** (Overlay tab): the Latency and frame gen toggle is now one of three lit / unlit buttons on one line: LATENCY, REFRESH, BATTERY. Off = gone from every level and not read at all (refresh off also stops the vblank counter). Latency stays off by default, refresh and battery on.
- **Level 3 shows the refresh rate** (DISPLAY row under BATT), like level 4.
