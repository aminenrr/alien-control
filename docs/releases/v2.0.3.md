**Alien Controls 2.0.3**: overlay and sensor accuracy fixes on top of 2.0.2.

### Changed
- **Overlay graph and numbers react faster**: Alien Controls now asks Windows to hand PresentMon's frame data over every 50 ms instead of waiting up to a second. The frame graph follows the game about 0.2 s behind instead of 1.5 s or more, with no extra CPU load. Still the official PresentMon 2.6.0, nothing injected.
- **Steadier frame graph**: the graph now plays a fixed 180 ms behind the game instead of a delay that grew after every hitch.
- **GPU USE matches RTSS**: when the RTX is on and working, GPU USE comes from the NVIDIA driver (the same number RTSS and the NVIDIA overlay show). It used to read 10 to 15 points low. With the RTX asleep or off, nothing changes and the RTX is never woken just to read it.
- **Same latency rows on dGPU and Optimus**: DISP LAT (frame start to screen) is shown in both GPU modes. Games with Reflex also show PC LAT above it, so the two modes can be compared.
- **VRR / G-SYNC row follows the screen's GPU** (level 2): in Optimus the Intel GPU drives the screen, so the row says VRR On / Off in Intel blue. In dGPU mode it says G-SYNC On / Off in NVIDIA green.
- **Tidier levels 3 and 4**: small gaps between groups (time, GPU, CPU and cores, VRAM and RAM, battery, fans, display info, fps). FPS now sits under MODE with the lows and the graph, FAN is now FANS, and latency is one LAT row (display latency, plus PC latency with Reflex).
