**Alien Controls 2.0.0-beta1.3-ov.7** (overlay preview, pre-release): on top of **beta1.3**, without the beta1.4 fixes. Includes everything from [ov.6](https://github.com/aminenrr/alien-control/releases/tag/v2.0.0-beta1.3-ov.6).

### Fixed in ov.7
- **RR / DISPLAY shows the real refresh rate**, like RTSS. It was the display mode (always 240 Hz). Now it counts the panel's real vblanks on the monitor the game is on, so with G-Sync it moves with the game. Runs only while a level shows RR (2 and 4); falls back to the mode's Hz if the count isn't available.
- **Frametime graph looks like SteamOS**: fixed 0 to 50 ms scale (MangoHud's default) instead of zooming into the min / max, which turned 1 ms of noise into big spikes.
- **New LIVE update option** (Overlay tab, Update every): numbers every 250 ms and the graph redrawn about 30 times a second, so it scrolls smoothly. Off by default (a little more CPU in this app, none in the game).
- F4 off then on again within 2 s no longer stops PresentMon a moment later (the overlay kept showing but FPS stopped).
