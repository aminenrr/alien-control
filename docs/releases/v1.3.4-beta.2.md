**Alien Controls 1.3.4-beta.2**: test build for the GPU OC Performance toggle.

### Changes
- GPU Overclock header has a new toggle with the Performance icon. Lit in the Performance colour: your kept offsets also apply in the Performance preset (plugged in). Dark (default): G-Mode only, as before.
- Switching into or out of Performance applies or drops the offsets. Battery still means +0.
- With the toggle lit, the header label reads G-MODE + PERF in your lighting colour.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
