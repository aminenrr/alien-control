# Alien Controls 2.0.0-beta2.2

Fixes FPS and the frametime graph again (beta2.1 still showed 0 FPS in Castlevania and Control, frametimes of seconds).

- Real cause: beta2 started tracking frame type in normal mode. Without display tracking that made PresentMon hold presents until its buffer overflowed (thousands dropped per run), so frames arrived seconds late or not at all. Normal mode is back to the ov.14 PresentMon setup that worked
- FPS like RTSS: every presented frame counts again, frame gen included. No more guessing which frames are generated. The graph and 1% / 0.1% lows use every frame too
- The FG count next to FPS (Latency toggle on) still shows the generated share when PresentMon reports it
