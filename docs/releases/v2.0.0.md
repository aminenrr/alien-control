**Alien Controls 2.0.0**: the 2.0 look plus a built in game overlay. Every 1.3.5 feature is still here.

### What's new since 1.3.5
- **New window**: Home, Tuning, Lights and Overlay tabs, Legend theme. Home has the presets, Tuning keeps every perf mode incl. G-Mode, fans Auto / Max Boost.
- **F3** opens and hides the app. **F4** turns the overlay off / back to the last level, **Shift + F4** cycles levels.
- **In game overlay** (replaces RTSS): PresentMon frametimes, no injection, click through, Direct2D drawing.
  - 4 levels like MangoHud presets, level 2 in the Apple Metal HUD style (JetBrains Mono, FPS / 1% low / max, frame interval, graph, GPU / CPU, memory, G-SYNC, latency).
  - Optional rows: clock, latency + present mode, CPU / GPU bound.
  - Off means nothing runs. The overlay only reads what its level shows.
- **FPS cap and driver V-Sync** per game on the Overlay tab (NVIDIA profile, kept across relaunches).
- Lighter: sensors only poll while a page that shows them is open.
