**Alien Controls 2.0.0-beta1.6** (pre-release): a newer version now takes over from the one already running. Same layout and features as beta1.5.

### Changed
- **Updating no longer needs Quit first.** Before, starting a new version while the old one sat in the tray only opened the old window and closed the new one, so the update (and the Program Files copy for Run on startup) never happened. Now a newer version asks the running one to quit (same clean exit as Quit: overclock and CPU cap put back, no iGPU prompt) and carries on in its place. An older or equal version still just opens the running window.
- This works from beta1.6 on. beta1.5 and older don't listen yet, so for this one update: **Quit beta1.5 from the tray first**, then start beta1.6. (If you forget, beta1.6 waits about 15 s, then opens beta1.5's window as before.)

### Fixed
- crash.log no longer gets a `Startup.GetTask: FileNotFoundException` warning at every start (it only meant "no task by that name").

### What to test

- [x] crash.log after the reboot has no `Startup.GetTask` warning.
- [x] Start beta1.6 again while it is running: its window opens, nothing else happens.
