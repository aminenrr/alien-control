**Alien Controls 1.1.1**: name fix.

### Changes
- Windows startup lists and Task Manager now show **Alien Controls** instead of "AlienControl".
- The run-on-startup task is renamed to "Alien Controls". If you had run on startup on, the old task is replaced automatically the first time 1.1.1 starts.

Updating from 1.1.0: replace `AlienControl.exe`, keep the CLIs. Settings stay in `%AppData%\AlienControl`.
