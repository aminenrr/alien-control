# Alien Controls 2.0.0-beta3

Overlay levels reworked (Amine):

- Level 1 (FPS only) is gone. The one line strip (old level 2) is level 1 now and keeps its look
- New level 2: a macOS Metal HUD style panel, monospace, label on the left and value on the right:
  - clock on top (with its Show on overlay tile)
  - resolution, plus the flip mode (iFlip / Composed) with the Latency toggle
  - VRAM and RAM
  - G-SYNC On / Off, read from the panel's real refresh (on when it follows the game). Can't tell while the game runs at the max refresh, so it keeps the last answer
  - FPS, 1% low, frame interval
  - frame interval graph: blue with a white grid, spikes in red, scale follows your frame rate
  - GPU and CPU load, temp, watts
  - PC Latency (or Disp Latency without Reflex) with the Latency toggle
  - no frame gen row and no fans
- Level 2 starts top right like macOS (your old level 2 size and background). Levels 3 and 4 are unchanged
