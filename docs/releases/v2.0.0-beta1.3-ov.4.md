**Alien Controls 2.0.0-beta1.3-ov.4** (overlay preview, pre-release): on top of **beta1.3**, without the beta1.4 fixes. Includes everything from [ov.3](https://github.com/aminenrr/alien-control/releases/tag/v2.0.0-beta1.3-ov.3).

### Fixed in ov.4
- **Microsoft Defender flagged ov.3** as `Behavior:Win32/DefenseEvasion.A!ml` (a machine learning guess from behavior, not a known virus). Each time the overlay turned off, the app launched a second hidden PresentMon only to kill an ETW trace session, and malware kills ETW sessions to blind antivirus.
- The app no longer stops any trace session itself. Turning the overlay off asks PresentMon to quit the way its own Ctrl+C does, and PresentMon closes its own session.
- `--stop_existing_session` is only passed when PresentMon reports a leftover session from a killed run (crash, Task Manager).
- Turning the overlay off is delayed 2 s, so F4 on / off / on keeps one PresentMon instead of restarting it each time.
- On Quit the app waits (up to 3 s) for PresentMon to close its session.
