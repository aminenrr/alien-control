**Alien Controls 1.3.0-beta.2**: new settings page, pill toasts, soft chimes.

### Changes
- Settings is now a page inside the window (gear, then back arrow or Esc) with five tabs: General, Keys, Alerts, Backlight, Advanced. No more long scroll.
- Toast style: **Pill** (new, top center) or **Classic** (the 1.2 card). Test button on the Alerts tab.
- Chime pack: **Soft** (new) or **Classic** (the 1.2 sounds), with a preview button.
- The new slide engine and the transparent window are now the only option (beta.1 A/B); the gear hitch is gone.
- Starting to the tray trims memory after 10 s instead of a minute.
