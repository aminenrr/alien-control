**Alien Controls 1.0.0**: a lightweight replacement for Alienware Command Center on the **Alienware m15 R7**, built on [T-Troll's alienfx-tools](https://github.com/T-Troll/alienfx-tools).

### Highlights
- **Presets** from the tray, the window or **F2**: Battery, Quiet, Balanced, Performance (power mode, CPU boost, refresh rate), plus Custom.
- **F1 G-Mode**: fans max, Aggressive boost, optional GPU overclock (AC only, keep-or-revert test).
- **F3** opens / hides the app from anywhere, borderless games included.
- **Auto preset**: Battery when unplugged, your last preset when plugged back in.
- Toasts + soft sounds for F1, F2 and plug / unplug, right on the key press.
- Fans, temps and CPU / GPU / total power while open.
- Per-key keyboard color and effects, chassis lights, status keys (G-Mode, mutes, touchpad) lit instantly.
- GPU mode: Advanced Optimus / Ultimate via the Dell BIOS switch.
- Legend and Fluent themes, Reduce motion, Reset settings.
- **Idle cost**: 0% CPU, ~20 MB open, a few MB in the tray. One ReadyToRun exe.

### Install
1. Install the [.NET 8 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/8.0) if you don't have it.
2. Stop and disable the AWCC services.
3. Unzip `AlienControl-1.0.0-win-x64.zip` anywhere and put `alienfan-cli.exe` and `alienfx-cli.exe` from the [alienfx-tools release](https://github.com/T-Troll/alienfx-tools/releases) next to `AlienControl.exe`.
4. Run it (admin), turn on **Run on startup**.

Updating from 0.9.x: replace `AlienControl.exe`, keep the CLIs. Settings stay in `%AppData%\AlienControl`.
