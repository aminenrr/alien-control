**Alien Controls 2.0.0-beta1.3-ov.6** (overlay preview, pre-release): on top of **beta1.3**, without the beta1.4 fixes. Includes everything from [ov.5](https://github.com/aminenrr/alien-control/releases/tag/v2.0.0-beta1.3-ov.5).

### New in ov.6
- **MODE row on level 4** (only with the Latency and frame gen toggle on, since it needs PresentMon's display tracking): how Windows presents the game.
  - **IFLIP** / **IFLIP MPO**: independent flip, what G-Sync / VRR wants in borderless and windowed.
  - **COMPOSED** / **COMPOSED COPY**: DWM composites the game, about one frame more latency and VRR may drop.
  - **FULLSCREEN**: exclusive fullscreen (legacy flip).
- Read from Windows through PresentMon, no NVIDIA setting needed. It shows the flip mode, not G-Sync itself; the NVIDIA G-SYNC indicator is the direct check.
