# Alien Controls 2.0.0-beta2.4

Frametime graph, from Amine's Castlevania and Control clips:

- One step per frame again, like MangoHud and RTSS (the last 200 frames across), but it slides by subpixels between frames so it still moves smoothly. In beta2 / 2.3 the graph was by time, so a 250 ms hitch drew as a wide triangle and a pause (loading, menu, alt tab) drew as a long straight line across the graph or left half of it empty. Now a hitch is one thin spike and a pause just stops the line
