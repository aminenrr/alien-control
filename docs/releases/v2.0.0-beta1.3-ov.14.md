# Alien Controls 2.0.0-beta1.3-ov.14 (overlay preview)

Smoother frametime graph and quicker FPS.

## Changes
- Frametime graph scrolls smoothly. PresentMon hands frames over in bursts, so the graph used to jump a chunk at a time. It now plays them back one frame at a time, a burst behind.
- The graph redraws about 30 times a second whenever it's shown, whatever "Update every" is set to.
- FPS is read over the last 250 ms, so the number follows the game quicker. "Update every" still sets how often the numbers change.
- FPS no longer flickers to 0 between PresentMon bursts (stale after 1.5 s instead of 1 s).

## Test
- [ ] Level 3 or 4 in a game: graph scrolls steadily, no jumps.
- [ ] Cap the game at 60, then 120: FPS number settles within about half a second.
