**Alien Controls 1.1.0-beta.2** (pre-release, for testing): Fluent Acrylic.

### Changes
- Fluent theme gets the native Windows 11 see-through blur (like Quick Settings). The accent still follows the laptop lights, and Legend is unchanged.
- New gear toggle "Transparency" (on by default). Turning it on or off, or switching between Legend and Fluent, restarts the app.
- Includes beta.1: sensors read straight from WMI.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
