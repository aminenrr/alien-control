# Alien Controls 2.0.0-beta1.3-ov.12 (overlay preview)

## Fix: Overlay tab fits again
- Size, Move left / right and Move up / down are now three small - / + boxes in one row instead of three sliders, so the Show on overlay buttons are no longer cut off at the bottom.
- Click - / +, or scroll over a box. Shift = 25 % for Size, 10 % for Move. Double click the number to reset (Size 100 %, Move 0).
