**Alien Controls 1.3.0-beta.1**: code review fixes, keyboard light timeout, CPU / GPU usage, smoother slides.

### Changes
- Fixes: single instance, startup task works on battery, no flicker from overlapping keyboard frames, F1 hook on its own thread, Auto preset no longer misses a quick replug, safer Quit (CPU cap cleared, RTX back on offer), Fast Startup safe Ultimate detection, re-check after sleep.
- Security: only T-Troll's alienfx-tools 9.6.x CLIs run (SHA-256 checked), `nvml.dll` only from System32, settings clamped, atomic settings save. Install into `C:\Program Files\Alien Controls`.
- New: keyboard light timeout (gear menu), CPU % / GPU % row.
- Smoother open, close, view switch and toasts (refresh-timed slide engine). Debug toggles to compare old and new.
- Each release now has a `SHA256SUMS` file.
