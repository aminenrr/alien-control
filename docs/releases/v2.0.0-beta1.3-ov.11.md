# Alien Controls 2.0.0-beta1.3-ov.11 (overlay preview)

Overlay-only build on `beta1.3-ov`. Merges into 2.0 later through `merge/beta2`.

## New: FPS CAP (Overlay tab)
- The NVIDIA driver's own Max Frame Rate, per game. Nothing is injected and nothing keeps running: the app writes the game's NVIDIA profile (the same one the NVIDIA app edits) once when you click.
- Presets OFF, 60, 120, 144, G-SYNC (refresh minus 3, 237 at 240 Hz) and ··· for your own number (click - / +, scroll, Shift = 10).
- THIS GAME = the last game the overlay saw in front. ALL = NVIDIA's global profile.
- V-Sync in driver toggle (Vertical sync: On for the game). G-SYNC turns it on, the Blur Busters setup: G-Sync + driver V-Sync + cap under refresh, V-Sync off in the game.
- The driver reads the profile when the game starts: restart a running game to apply. The status line says so.

## Changed
- Overlay background moved to the gear menu (General, one value for every level). Move left / right and up / down stay on the Overlay tab.
- Show on overlay says what's on ("On: refresh, battery").
- The level description moved to the level slider's tooltip to make room.

## Fixes
- FPS with more than one swapchain: frames from a second swapchain of the same game (launcher overlay, menu video, second window) no longer inflate the FPS or mix into the frametimes. Only the busiest swapchain counts.
- RAM: 30 s after the overlay goes off, its window and thread are torn down and memory is trimmed. PresentMon lines are parsed without allocating. Background GC off and GC ConserveMemory on.
