# Alien Controls 2.0.0-beta3.6

Level 2 (Metal) font:

- Level 2 now uses JetBrains Mono (bundled, SIL OFL), much closer to the SF Mono Apple's HUD uses (SF Mono can't ship on Windows). Cascadia Mono / Consolas stay as the fallback.
- The font files are copied to %LocalAppData%\AlienControl\Fonts and loaded privately, nothing is installed on the system.
