**Alien Controls 1.1.0-beta.4** (pre-release, for testing): compact view.

### Changes
- New gear toggle **Show in taskbar**: turn it off and the app only lives in the tray.
- The tray and F3 now open a compact window: sensors, power, performance mode and lighting colors. F4 opens the full menu.
- A footer button switches between Full menu and Compact. The version label moved next to the status line.
- Includes beta.3 (compact view) and beta.1: sensors read straight from WMI. (beta.2, Fluent Acrylic, was withdrawn.)

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
