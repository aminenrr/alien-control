**Alien Controls 1.3.3**: status keys stay lit.

### Fix
- Turning the rear ring or Alienhead off or on alone turned off the five white status keys (F1, F12, mute, mic, right Win), and they stayed off. The keyboard's frame, status keys included, is now sent again after every ring / Alienhead change, with no visible flash.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
