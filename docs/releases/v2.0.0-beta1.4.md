**Alien Controls 2.0.0-beta1.4** (pre-release): the rest of the 2.0 code review (Tier 2 performance and Tier 3 cleanup), a fix for lost settings saves, and five small visual changes. Same layout as beta1.3. The in-game overlay comes in beta 2.

### Fixed
- **Run on startup now runs a copy in Program Files, so other programs can't swap the file that starts as admin at logon.** The startup task starts the app as admin with no prompt. Before, it pointed at the folder you extracted the zip to (usually Downloads or the Desktop), which any program can change. Turning Run on startup on now copies the app to `C:\Program Files\AlienControl` (admins only) and the task runs that copy. A task from an older version is moved there on the first start (or turned off with a note in the status line if that fails), and running a newer version from anywhere updates the copy. No temporary file is written any more. Turning Run on startup off deletes the task and removes the Program Files copy. Your settings in `%AppData%\AlienControl` are not touched.
- **NVIDIA tray icon after iGPU only**: switching back to Advanced Optimus left NVIDIA's display mode icon missing until a reboot. The app now always restarts NVIDIA's Display Container once the RTX is up and waits for each step, so the icon and the display mode popup come back.
- **GPU overclock while the RTX is off**: in iGPU only the GPU OVERCLOCK card stayed editable and Home still showed the kept offsets. The card is now greyed with a short hint, Home shows "GPU overclock off while the RTX is off", toasts show no OC tag, and nothing is written to the driver. It all comes back with the RTX.
- Removed the Log frame gaps debug option.
- **Settings not saved**: if anything held settings.json open for a moment (antivirus, the search indexer, an editor), every save failed with "Unable to remove the file to be replaced" and the change was lost (one log had about 28 lost saves in 6 minutes). Saves now clear read-only flags, retry, then copy over the file. If that still fails, the newest settings are kept and written by the next save, a 2 s retry, or on quit. crash.log gets one warning per streak instead of one per save. A damaged settings.json is moved aside as `settings.json.corrupt` so it never becomes the backup, and settings this version doesn't know (for example from a newer build) are kept.

### Faster and lighter (Tier 2)
- GPU % and VRAM come from one Windows performance query, and every Home reading (RAM, VRAM, CPU %, GPU %) runs off the UI thread. The old full GPU Engine dump every 2 s on the UI thread is gone.
- Presets change the power plan in-process (powrprof) instead of starting 5 powercfg.exe processes, with powercfg as a fallback.
- G-Mode state is read once at startup and shared, instead of extra `getgmode` runs on start and on most preset changes.
- The GPU device query (Win32_PnPEntity) only runs while Tuning is on screen, at most every 10 s.
- The NVIDIA (NVML) session closes on battery and whenever the app stops polling (hidden, minimized, a page without sensors), and reopens when needed.
- Light animations reuse their buffers instead of allocating about 10,000 objects a second.
- Lighting colour and preset changes skip work when nothing actually changed (brushes, tray icon, toasts).
- **WPF-UI and the PerformanceCounter package are removed.** Tooltips, text boxes and scrollbars have their own Legend styles. The exe goes from 11.6 MB to 3.7 MB and the zip from about 5.0 MB to 2.3 MB.

### Cleanup (Tier 3)
- Dead code removed: the 20 s F7 probe, the GPU support report, the old Fluent theme branches, compact view leftovers, unused Dell BIOS calls (password, Express charge) and other unused helpers. 69 unused theme keys pruned.
- MainWindow.xaml.cs (about 1,780 lines) is split into partial files (Window, Sensors, Modes, Gpu added next to Lights, Presets, Settings, Tabs, Oc, Kbd, Auto). No behaviour change.
- An error inside a button or menu handler is logged and shown in the status line instead of closing the app (a burst of them, or a fatal one, still runs the crash cleanup).
- Faint hint text is a bit brighter (#76828E) to meet WCAG AA contrast. Icon-only buttons, swatches, sliders and toggles have names for Narrator.
- The keyboard search backs off 1.5 s after a failed open, and the brightness slider commits on arrow and Page keys.
- Build: Dependabot now finds the NuGet projects, CI caches NuGet and cancels superseded runs, the XAML key check is `dev/check_xaml_keys.py`, the release checks the tag against the app version and the notes file before building, and the zip includes LICENSE. New tests check that every theme key loads and resolves, there are no dashes in UI text, every swatch shows the colour it sends, the sounds load, the version has notes, and settings round trip.
- The Legend.xaml generator is retired (`dev/retired/gen_themes.py`); Legend.xaml is now edited by hand.

### Looks (Amine's calls)
- **Green swatch** shows #3CFF7A, the green the keyboard actually gets (was a darker #40DC78).
- **Selected fills follow your lighting colour**: lit zone tiles, selected pills, segment buttons, toggles and the chip use a dark tint of the current colour instead of fixed teal. Tiles use their own colour (Home preset tiles keep their preset colour), white gives a weaker neutral grey, Rainbow and Spectrum use the cyan fill.
- **Keyboard focus ring**: Tab and the arrow keys show a thin accent outline around the focused control. Mouse clicks show nothing.
- **Short screens**: when the usable screen is shorter than the window needs (under 848 DIP, for example 1080p at 150 %), the whole window scales down to fit, so the footer never hides under the taskbar. Screens that fit are unchanged.
- **Tooltips, text boxes and scrollbars** in the Legend style (dark card, accent border on focus, thin accent scrollbar thumb). Tooltips use the normal UI font so long ones stay readable.

Mockups: `docs/mockups/2.0-beta1.4/`.

### Known trade-offs
- With Rainbow or Spectrum on, fills use cyan but text and borders keep the last colour you picked.
- The slide's GC change from the review was not made; it needs an A/B on the laptop.
