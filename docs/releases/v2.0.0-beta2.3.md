- Frame gen graph (Amine: Control zigzag 0.3 / 14 ms, 1% low 28 at 137 FPS): with the Latency toggle on, the frametime graph, FPS and lows follow what reaches the screen (MsBetweenDisplayChange, like PresentMon's own overlay) instead of when the game presented. - Honest latency label: LATENCY is now DISP LAT (present to screen only). PC LAT (Reflex, input to screen, includes render and frame gen delay) shows when the game sends Reflex markers
