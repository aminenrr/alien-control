# Alien Controls 2.0.0-beta1.3-ov.15 (overlay preview)

The overlay now draws with Direct2D. This build also adds temps on level 2, Shift + F4 for levels, a clock, a CPU / GPU bound estimate and a stutter counter.

## Changes
- **Direct2D overlay window.** The HUD is drawn by the GPU and handed to Windows' compositor (DirectComposition). There's no CPU copy of the whole overlay every frame any more. The look is the same SteamOS / MangoHud style, and it's still a separate window on top of the game (no injection).
- **Smooth graph.** The frametime graph is plotted by time, not by frame. The newest frame sits on the right edge, the graph shows 2 seconds, and it slides at a steady speed, redrawn every refresh while it's on screen. With no graph shown (level 1), it only redraws when the numbers change.
- **WPF fallback.** If Direct2D can't start, or loses its GPU 3 times in a minute, the overlay goes back to the old WPF window by itself. To compare the two, set `"OverlayRenderer": "wpf"` in settings.json (`"d2d"` is the default). The WPF graph now also redraws every WPF frame instead of every 33 ms.
- **Built-in measurement.** Every 10 s while the overlay is shown, crash.log gets a line like `Overlay perf: d2d, 144 Hz, 1438 frames in 10 s, 2 missed, 0.4 % CPU`. Missed means a refresh with no new frame while the graph was moving.
- **Level 2 temps.** CPU and GPU °C are added after the load %. They come from the same 2 s sensor poll as level 3.
- **Temp colours on levels 2 to 4.**
  - CPU: green under 80, yellow 80 to 89, red at 90 and up.
  - GPU: green under 75, yellow 75 to 79, red at 80 and up.
  - Green #39F900, yellow #FDFD09, red #FF3B3B.
- **Shift + F4** cycles levels 1 to 4. 4 wraps to 1, and from off it starts at 1. F4 alone still turns the overlay off or back to your last level. Alt is not used, because Alt + F4 closes the game.
- **Clock row** (levels 3 and 4): HH:mm at the top. Off by default, with a new CLOCK tile under Show on overlay.
- **BOUND row** (levels 3 and 4), under the FPS row:
  - GPU EST or CPU EST is an estimate from how busy the GPU is for each frame.
  - LIMITED (yellow) means the NVIDIA FPS cap or V-Sync is holding the game.
  - Off by default, with a new BOUND tile. Only while it's on, PresentMon also tracks GPU work.
- **STUTTER row** (levels 3 and 4), under LATENCY:
  - Counts frames over 2x the median in the last ~10 s, and shows the worst one in red.
  - Generated frames are ignored.
  - Spikes get red marks on the graph (levels 2 to 4).
- The Overlay tab header now reads `F4 · OFF · SHIFT+F4 · LEVEL`.

## Before you test
- This is the overlay branch (beta1.3 base, without the beta1.4 to 1.6 fixes). Quit 1.6 from the tray first, then run this build from its own folder.
- If Start with Windows is on, this build points it at itself. When you're done, start 1.6 once and it moves it back to Program Files.

## What to test
- [ ] Footer reads v2.0.0-beta1.3-ov.15.
- [ ] crash.log says `renderer: Direct2D on ...` with your GPU's name.
- [ ] Levels 1 to 4 show over a game, and clicks go through the overlay to the game.
- [ ] The overlay never takes focus from the game.
- [ ] Level 3 or 4 in Control, frame gen off and then on: the graph slides smoothly, close to RTSS.
- [ ] The crash.log `Overlay perf:` lines show few missed frames and low CPU. Note the numbers.
- [ ] Optional A/B: set `"OverlayRenderer": "wpf"`, restart the app, and compare the perf lines in the same spot.
- [ ] Level 2 shows CPU and GPU temps after their load %, and the row still fits on screen.
- [ ] Temp colours change at the thresholds above (a heavy game gets the GPU past 75).
- [ ] Shift + F4 goes 1, 2, 3, 4, 1. From off it starts at 1.
- [ ] **Shift + F4 never closes the game.**
- [ ] In crash.log, the F4 lines don't say `VK_F4 down too`. If they do, tell me: the key also sends a real F4.
- [ ] F4 alone still turns the overlay off and back to your last level.
- [ ] CLOCK tile: the time shows on levels 3 and 4 only, and is gone when the tile is off.
- [ ] BOUND tile:
  - It reads GPU EST in a heavy scene.
  - With an FPS cap set lower than the game reaches, it reads LIMITED.
  - Off by default.
- [ ] STUTTER row: 0 when the game is smooth. A hitch (loading, alt tab back) counts one, shows the worst ms in red, and puts a red mark on the graph.
- [ ] Advanced Optimus: overlay on, launch a fullscreen game so the screen switches to NVIDIA. No crash, at most a blink. crash.log may show `Direct2D device lost (1), rebuilding`.
- [ ] Sleep and wake with the overlay on: it comes back.
- [ ] F4 off, wait 30 s: crash.log says `window torn down after idle`, and RAM drops as before.
