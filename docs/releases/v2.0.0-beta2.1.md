# Alien Controls 2.0.0-beta2.1

Fixes beta2's broken FPS numbers and frametime graph (0 FPS, 1100 to 2600 ms frametimes in Castlevania and Control).

- Frame type: PresentMon 2.6 sends types beta2 didn't know (Unspecified), and every unknown type was counted as a generated frame, so no real frames were left. Now only frame gen types count (Intel XeFG, AMD AFMF, DLSSG, anything naming FG or frame generation)
- Time column: with frame type tracking on, PresentMon prints CPUStartTimeInMs / TimeInMs instead of seconds. Both are read now (converted to seconds); arrival time is the fallback if there is no time column at all
- PresentMon event buffer raised to 8192 (the log showed up to 37771 dropped presents)

- [ ] Control with frame gen on: FPS + generated FPS split still right, no zigzag
