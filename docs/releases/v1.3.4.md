**Alien Controls 1.3.4**: GPU overclock in the Performance preset, OC state on notifications.

### Changes
- GPU Overclock header has a toggle with the Performance icon. Lit in the Performance colour: your kept offsets also apply in the Performance preset (plugged in). Dark (default): G-Mode only, as before. On battery the OC is always +0.
- With the toggle lit, the header label reads G-MODE + PERF in your lighting colour.
- The Performance and G-Mode on toasts show the OC state: "OC +core / +mem" in the Performance colour when it runs, grey "OC off" when it doesn't. The Classic toast gives it its own line.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
