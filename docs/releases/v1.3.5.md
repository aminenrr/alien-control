**Alien Controls 1.3.5**: everything from 1.3.3 and 1.3.4 together.

### Fix
- 1.3.4 was built without the 1.3.1 to 1.3.3 changes. They are back: the Lights menu (Keyboard, Rear ring, Alienhead, Turn off / Turn on), Ctrl + Alt + F, the restyled tray menu, no-flash light switching and status keys that stay lit.
- The 1.3.4 GPU OC features stay: the Performance toggle in the GPU Overclock header, the G-MODE + PERF label and the OC state on the Performance and G-Mode on notifications.
- Pill notification: the OC state now sits on its own line, so it fits the smaller pill.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
