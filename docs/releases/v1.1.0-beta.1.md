**Alien Controls 1.1.0-beta.1** (pre-release, for testing): sensors read straight from WMI.

### Changes
- CPU / GPU temperature and both fans now come from the Alienware WMI instead of starting `alienfan-cli` every 2 seconds, so the app uses less CPU while the window is open. alienfan-cli is still used for presets, G-Mode and fans, and as a fallback if WMI reads fail.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
