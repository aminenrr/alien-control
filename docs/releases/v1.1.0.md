**Alien Controls 1.1.0**: compact view, faster sensors and a cleaner header.

### Changes
- **Compact view**: the tray and **F3** open a short window (sensors, power, performance mode, lighting colors). **F4** or the new footer button opens the full menu. F3 / F4 hide it again.
- **Faster sensors**: CPU / GPU temps and fan speeds now come straight from the AWCC WMI interface (~2.5x faster than the CLI), with alienfan-cli as fallback.
- **Preset button**: the header chip is now a button next to minimize. Click it to pick a preset from a list with icons and colors.
- **Show in taskbar** toggle in the gear menu: turn it off and the app only lives in the tray.

Updating from 1.0.0: replace `AlienControl.exe`, keep the CLIs. Settings stay in `%AppData%\AlienControl`.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
