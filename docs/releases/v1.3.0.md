**Alien Controls 1.3.0**: settings page, pill toasts, soft chimes, keyboard light timeout, smoother and safer.

### Changes
- Settings is a page inside the window (gear, back arrow or Esc) with five tabs: General, Keys, Alerts, Backlight, Advanced.
- Toast style: **Pill** (top center, new) or **Classic** (1.2 card). Chime pack: **Soft** (new) or **Classic**, with preview. No more chime crackle from the app side.
- Keyboard light timeout (1 / 2 / 5 / 10 min, battery only, not in fullscreen games) and a CPU % / GPU % row.
- Smoother open, close, view switch and toasts (refresh-timed slide engine).
- Fixes from a full code review: single instance, startup task on battery, no keyboard flicker, F1 on its own thread, quick replug handled, safer Quit.
- Security: only T-Troll's alienfx-tools 9.6.x CLIs run (SHA-256 checked), `nvml.dll` only from System32, settings clamped and saved atomically. Still zero network access. Each release has a `SHA256SUMS` file.

Unofficial fan project, not affiliated with Dell or Alienware. Built with the help of AI and tested only on one m15 R7; it changes fans, power, BIOS GPU mode and GPU clocks, so use it at your own risk. See the [Disclaimer and AI disclosure](https://github.com/aminenrr/alien-control#disclaimer).
