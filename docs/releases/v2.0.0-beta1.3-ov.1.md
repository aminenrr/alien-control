**Alien Controls 2.0.0-beta1.3-ov.1** (overlay preview, pre-release): the in-game overlay on top of **beta1.3**. This build does **not** have the beta1.4 fixes. It is only for testing the overlay; the overlay and beta1.4 get merged into 2.0.0-beta2. See [docs/BRANCHES-2.0.md](https://github.com/aminenrr/alien-control/blob/beta1.3-ov/docs/BRANCHES-2.0.md).

### New: in-game overlay (MangoHud / SteamOS style)
- **4 levels like the Steam Deck**, copied from MangoHud's presets:
  - **1**: FPS only.
  - **2**: one line: FPS, frametime + graph, CPU and GPU load and watts, RAM, VRAM, battery.
  - **3**: the full HUD: GPU load, temp, watts, core and memory clock; CPU load, temp, watts, clock; VRAM, RAM, battery, engine (DX12, DX11, VULKAN, OPENGL), FPS, frametime graph.
  - **4**: level 3 plus load per CPU thread, fan RPM, refresh rate, 1% low and max frametime.
- MangoHud look: #020202 background at 50 %, square corners, MangoHud label colours, green frametime graph, units in a smaller font.
- **Frametimes from PresentMon 2.6** (Intel, MIT): ETW, no injection, anti cheat safe, no RTSS. It follows the window in front.
- **F4**: overlay off, or back to your last level (toast shows which). **Home** and the **Overlay** tab have the OFF 1 2 3 4 slider (click, drag or arrow keys).
- **Overlay tab**: live preview of the level with sample values, position (6 spots), size (100 % = SteamOS size), background, update every 250 / 500 / 1000 ms, Reset to SteamOS.
- Click-through, never takes focus, no taskbar button, on its own UI thread.

### Efficiency
- **Off = nothing runs**: PresentMon stopped, overlay window hidden, no extra timer.
- **Level 1 reads frames only.** Level 2 adds usage and power, level 3 adds temps and clocks, level 4 adds per thread load, fans and refresh rate.
- Sensors come from the app's own pollers (2 s sensors, 1 s power), shared with Home and Tuning, never read twice. CPU % has one reader for both.
- PresentMon runs with display, GPU and input tracking off (cheapest mode) and dies with the app, even on a crash.

### Known limits (preview)
- Works over **windowed and borderless** games. **Exclusive fullscreen** games draw over it (set the game to borderless).
- Per level customizing (the checklist from the mockup) comes in a later preview.
- MangoHud's network row isn't copied.
- CPU clock is what Windows reports (can read low on some Intel CPUs).
