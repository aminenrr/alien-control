**Alien Controls 2.0.0-beta1.3-ov.2** (overlay preview, pre-release): the overlay on top of **beta1.3**, without the beta1.4 fixes. Only for testing the overlay; it gets merged with beta1.4 into 2.0.0-beta2. See [docs/BRANCHES-2.0.md](https://github.com/aminenrr/alien-control/blob/beta1.3-ov/docs/BRANCHES-2.0.md).

### New in ov.2
- **Per core view (level 4)**: one row per core, P cores first then E cores (P1 to P6, E1 to E8 on the i7-12700H). Each row shows its threads' load and the core's **real clock**.
- **Real CPU clock**: level 3's CPU MHz no longer sticks at the 2300 MHz base clock.
- **Move the overlay**: Move left / right and Move up / down sliders on the Overlay tab, in % of the screen from the chosen spot. Double click a slider to reset it. The overlay never leaves the screen.
- **Latency and frame gen** (Overlay tab toggle, **off by default**):
  - On: levels 2, 3 and 4 show **real FPS | generated FPS** (Steam style). With no generated frames, only the real FPS shows.
  - Latency: **PC LAT** when the game sends Reflex style latency markers, otherwise PresentMon's display latency (frame start to screen). Not the same number as NVIDIA's overlay in every game.
  - Off: PresentMon runs exactly like ov.1 and collects none of it. Flipping the toggle restarts PresentMon. Level 1 never changes.
- Graph caption reads min / max in ms.

### Known limits (preview)
- Generated frames are spotted by PresentMon's frame type. Some frame gen (mods, some drivers) may not be tagged; then the overlay shows all frames as real. Please test with DLSS FG (the sm86 mod) and FSR 3.
- Exclusive fullscreen, per level customizing and the network row: still not done.
