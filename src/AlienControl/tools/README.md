# tools/

Drop T-Troll's binaries here (from `alienfx-tools.zip` in the latest release at
https://github.com/T-Troll/alienfx-tools/releases):

- `alienfan-cli.exe` – fans, power modes, G-Mode, GPU limit, CPU boost, temps
- `alienfx-cli.exe` – keyboard / chassis lighting

They are copied next to `AlienControl.exe` on build. They are not committed
to this repo. alienfx-tools is MIT licensed, © T-Troll.
